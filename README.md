# Data Generation and Classification — Module Project

Java 8 / Eclipse project for the module **Conceptos Fundamentales de
Programación** (Politécnico Grancolombiano). Delivery type: design of a
documented Java program.

## Current status: Entrega 2 (Semana 5) - Preliminary Full Project

This delivery includes the complete preliminary version of the project. It contains both required entry points:
1. **`GenerateInfoFiles`**: Generates the pseudo-random flat files (products, salesmen, and individual sales).
2. **`Main`**: Reads the generated files, processes the sales data, and creates two sorted CSV reports:
   - `salesmen_report.csv`: Salesmen ranked by total money collected (descending).
   - `products_report.csv`: Products ranked by total quantity sold (descending).

A `MISSING_PARTS.txt` document is included, detailing the advanced features (serialization, multi-file processing, and advanced validation) that will be completed in the final delivery (Entrega 3).
